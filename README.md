# LOL Quiz v3.6 — 통합 난이도 설정 🌸

11가지 퀴즈 유형을 유지하면서 난이도 선택을 **한 화면에서 한 번만** 하도록 변경했습니다.

## 시작 흐름
1. 문제 수 선택 (10/20/50/173)
2. 문제 유형 선택 (11가지 중 복수 선택)
3. 전체 게임 난이도 선택 (쉬움 / 보통 / 어려움)
4. 게임 시작

## 난이도 적용
- 초상화와 일러스트 조각: 기존 확대 배율을 통합 난이도에 연동.
- 롤 상식 및 e스포츠: 선택 난이도의 문제를 우선 배치. 문제은행이 부족하면 다른 난이도의 문제로 보충합니다.
- 챔피언 식별 문제: 어려움일수록 챔피언 이름 길이가 유사한 오답 선택지를 우선 배치합니다.
- 스킬/스킨/아이템 등의 단서 자체는 원본 데이터 기준이며, 모든 유형이 동일한 강도로 어려워지는 것은 아닙니다.

기존 게임 진행 기록 및 설정 저장 유지. 캐시 버전 v3.6.
